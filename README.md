PS5 Amazon WebScraper

Scrapes the Amazon Website and sends an e-mail via SMPT indicating if the PS5 Console and PS5 Controller is in stock


## Installation

Clone the repository onto your computer and after creating a virtual environment, run 

```
pip install -r requirements.txt

```
